# Aktualizace pouze v telefonu

Repozitář nyní obsahuje pracovní návrh GitHub Actions pro podepsané APK a vydávání GitHub Releases. Postup zprovoznění a upozornění k podpisům najdeš v [AUTOMATICKE_SESTAVOVANI_APK.md](AUTOMATICKE_SESTAVOVANI_APK.md).

**Pozor:** dokud nejsou na GitHubu zaregistrované Secrets a neproběhne úspěšný sestavovací běh, žádné hotové APK dostupné není. Bez shody s původním podpisovým certifikátem nelze aktualizovat již nainstalovanou aplikaci bez ztráty dat.
